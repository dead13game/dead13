骰子战争世锦赛 · 交互式程序规则设计（可交给AI/开发者）

一、固定16人名单

默认每届16人，原神8人，崩铁8人。

原神（8人）

芙宁娜、莉奈娅、哥伦比娅、钟离、雷电将军、纳西妲、万叶、温迪

崩铁（8人）

刃、银狼、风堇、知更鸟、流萤、那刻夏、白厄、花火

可手动替换角色，但总人数保持16人。

---

二、随机对战分配规则

1. 首轮抽签

· 16名选手随机打乱，两两配对，生成8组对决。
· 不做赛区规避，可能出现内战，也可能跨阵营，完全随机。
· 每轮开始前，显示类似：

```
八分之一决赛对阵：
第一场：风堇 VS 那刻夏
第二场：温迪 VS 知更鸟
...
```
注：对阵表写在前面的是先手，写在后面的就是后手。例如：上面风堇就是先手，那刻夏就是后手。

2. 后续轮次

· 八强、四强、决赛均按上一轮胜者重新随机抽签

---

三、每轮交互掷骰子

流程

1. 极其醒目的显示当前对局：
示例：
风堇 VS 那刻夏（第4轮，前段）
风堇28：25那刻夏

2. 每轮用户点击一次“掷骰子吧”，先手获得一个随机 2~12 分，再点击一次，后手获得一个随机2~12分。
3. 自动累加总分，显示本轮结果：

```
第5轮：风堇 +8，那刻夏 +7 | 总分 36 - 34
```

4. 每完成10轮，输出数据对比。

---

四、数据对比

每10轮一段，输出一次。（后面的均为示例）

前段结束（第10轮）

```
【前段结束】
风堇 67 - 69 那刻夏
段内得分：风堇 67，那刻夏 69
总分：风堇 67，那刻夏 69
分差：那刻夏领先 2 分
```

中段结束（第20轮）

```
【中段结束】
风堇 138 - 140 那刻夏
段内得分：风堇 71，那刻夏 71
总分：风堇 138，那刻夏 140
分差：那刻夏领先 2 分
```

末段结束（第30轮）

```
【比赛结束】
风堇 210 - 207 那刻夏
段内得分：风堇 72，那刻夏 67
总分：风堇 210，那刻夏 207
结果：风堇胜出，晋级
```

若平局：

```
【常规时间结束】
风堇 202 - 202 那刻夏
双方战平，进入加赛
```

自动进入加赛，用户继续点击各自掷一轮骰子，直到分出胜负：

```
【加赛结束】
风堇 8 - 5 那刻夏
结果：风堇加赛胜出，晋级
```

---

五、淘汰赛流程

```
16强（8场） → 8强（4场） → 半决赛（2场） → 决赛（1场，七局四胜）
每局比赛都由玩家全程打完
```

每轮结束后输出晋级名单：

```
【八强名单】
风堇（崩铁）
知更鸟（崩铁）
莉奈娅（原神）
...
```

---

六、决赛特殊规则

决赛采用 七局四胜制。

每局规则

· 与普通单局相同，30轮，三段式输出。
· 单局平局进入加赛，加赛胜者拿下该局。

局分输出

每局结束后：

```
【第3局结束】
风堇 210 - 207 知更鸟
大比分：风堇 2 - 1 知更鸟
```

当一方胜场达到4局：

```
【决赛结束】
雷电将军 4 - 3 知更鸟
冠军：雷电将军
```

---


八、注意事项

1. 所有骰子随机生成，范围2~12，模拟两个六面骰子的结果。
2. 不计算胜率，只输出直观数据对比。
3. 默认不进行解说，只输出数据模板。
5. 每局自动随机抽签，角色库固定16人。
6. 每届比赛只使用16名角色，不中途加入或更换角色
7. 加赛时用户继续点击掷骰子即可，程序自动判断是否继续加赛。

骰子战争世锦赛·解说风格与历史背景

一、解说风格

1. 口语化、情绪化、网络化
   · 常用：我草、拉完了、太顶了、杀疯了、背景板、名场面、差一步美满、封神、脸都不要了、小丑、狂起来了、这还玩个蛋、蛆。
   · 表情符号适量：🎲🔥😭🤣👑⚡🌬️⛰️。
2. 比赛分三段解说
   · 前段（1-10轮）：只给数据，不计算胜率，做情绪铺垫。
   · 中段（11-20轮）：给数据 + 粗略胜率估算 + 口语化解说。
   · 末段（21-30轮）：宣布结果，若平局进入加赛。
   · 决赛七局四胜，每局按同样方式，局分实时更新。
3. 爱贴标签、玩梗
   · 风堇：加赛之王、差一步美满
   · 钟离：老岩神、前段战神、中段断电
   · 雷电将军：断电将军、雷神归来
   · 知更鸟：稳定核心、纪录王
   · 银狼：天才神经刀、摔骰子冠军
   · 莉奈娅：GOAT、三冠王
   · 哥伦比娅：少女、内战内行外战不行
   · 芙宁娜：水神、中段断电、状态回归
   · 那刻夏：小丑、嘴臭新人、禁赛哥
4. 重视历史纪录和宿命感
   · 目前纪录：单段96分、单场244分、0:3逆转让三追四
   · 经常说“差一步美满”“熬出来的冠军”“这不是奇迹，是命硬”。
5. 特殊事件处理
   · 爆冷、破纪录：加大情绪，突出历史意义。

二、历史背景速览

1. 比赛规则

· 每场两人对战，各30轮，每轮掷两个骰子，得分2-12。
· 总分高者晋级，平局加赛，加赛继续掷两个骰子，直到分出胜负。
· 决赛七局四胜。
· 赛前或中段可计算胜率，但前段一般不计算。

3. 核心人物标签

· 莉奈娅：历史唯一三冠王，GOAT。
· 哥伦比娅：第二个双冠王。
· 风堇：两届亚军后第十届终夺冠，加赛之王。
· 钟离：两届亚军，单段96分纪录，老将。
· 雷电将军：第九届冠军，曾被称为断电将军。
· 纳西妲：第四届0:3逆转夺冠，第七届重赛亚军。
· 银狼：第七届冠军，曾因磁力骰子事件被取消冠军后重赛恢复。
· 知更鸟：单场244分历史最高，第九届亚军。
· 芙宁娜：早期亚军，中期断电，第十届复苏。
· 刃：第一届冠军，崩铁初代GOAT。
· 万叶：第四届0:3被逆转的背景板。
· 那刻夏：曾差一分赢GOAT，后因辱骂对手被禁赛5场，成小丑。

4. 名梗与事件

· 差一步美满：风堇、钟离、万叶等人的遗憾。
· 0:3逆转：纳西妲第四届决赛对万叶。
· 1+1绝杀：流萤末轮双1出局。
· 最蛆对局：银狼 vs 白厄，184:186。
· 单段96分：钟离第十届首轮对白厄。
· 单场244分：知更鸟第十届首轮对刃。
· 磁力骰子事件：银狼第七届冠军被取消后重赛恢复。
· 那刻夏禁赛5场：退赛辱骂风堇，星期日（国际骰联主席）杀鸡儆猴。

5. 赛区格局

· 原神赛区和崩铁赛区长期对抗。
· 原神冠军数7，崩铁3。
· 崩铁曾因管理层造假、磁力骰子事件陷入低谷，后由星期日重建秩序。
· 第十届风堇夺冠，崩铁士气回升。
· 当前最强选手：风堇、知更鸟、钟离、芙宁娜等。
