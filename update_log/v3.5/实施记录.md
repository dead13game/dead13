## 一、规则修正

1. 天气固定顺序：烈日当空 → 暴雨倾盆 → 狂风呼啸 → 黑市交易 → 军备竞赛 → 风和日丽，循环。
   - 经典 / 世界杯 / 联赛 / 团战统一走 `rules/weather.js` 的 `WEATHER_CYCLE`。
2. 世界杯对手名单：R16 / QF / SF+Final 三份名单，按轮次抽取并避开本届已交手球队。
3. 世界杯总结：`matchHistory` 记录小组赛 3 场 + 每轮淘汰赛；淘汰/夺冠立即进入总结页，只能返回主菜单。
4. 联赛本轮结果：`主队（主） 胜/负/平 客队（客）`。
5. 联赛轮次：积分榜顶部显示实际已赛轮次（9/18，不再少一轮）。
6. 联赛收尾：18 轮后先出最终积分榜；仅当玩家与同分队存在时打一局附加赛（其余同分队随机模拟）；无同分直接回主菜单。
   附加赛选人后正常进入比赛，不再卡死。

## 二、伤害乘区（按补充说明）

- 总伤害 =（抽牌 + 烈日/月相/斗志/联赛等加法加成）× 圣遗物倍数，**再与陷阱点数比较**，最后围攻减半。
- 圣遗物从「陷阱后」移动到「陷阱前」；陷阱平局双方只吃陷阱点数。
- 薇斯纳：第 3/4/5+ 次连续攻击 ×1.5(ceil, ≥10) / ×2(≥15) / ×3(≥20)；任何非攻击操作、被冻结 → 清零。
- 菊雪梨：猜中 20+烈日；猜错无事；目标无陷阱 → 7+烈日、无视陷阱、吃圣遗物。
- 无人机：HP 5、每回合 3+烈日、吃圣遗物、只吃防御牌、永不设陷阱、当回合召唤后不能再行动、最多 1 架、主人阵亡一起消失、不算劣势补偿人数。
- 无人机在白子行动时攻击；原目标失效后：若原是塔则顺延下一座塔，否则自动攻击防御值最低的敌方英雄。

## 四、3v3 团战

- 入口：主菜单「👥 3v3 团战」。
- 设置：AI / 同屏双人、天气开关、蓝方 3 个圣遗物槽（同屏双人时红方也可选）。
- Ban/Pick：15 角色；A Ban1 → B Ban2 → A Ban1；A Pick1 → B Pick2 → A Pick2 → B Pick1。
- 对局：6 英雄 + 每队 5 塔（10 HP）；塔按 1→5 拆；英雄阵亡 5 回合后满状态复活（3 张防御牌、当回合第一个行动）；行动顺序按当前 HP 升序（复活者优先）；60 回合上限。
- 塔行动：所有角色行动完后，己方塔 ≥3 座 → 对敌方全体英雄+无人机 2 伤害；<3 座 → 3 伤害。塔吃天气与围攻减半，不吃劣势补给。
- 支援：防御可给自己/队友/己方塔；陷阱可给自己/队友/己方塔（诱饵留在自己）；技能按类型打塔/给盾。
- 胜负：拆光 5 塔；60 回合按 拆塔数 → 存活英雄数 → 总血量（含塔）→ 平局。
- 围攻：同一目标本回合第 2 次起攻击伤害减半（塔也吃，无人机不吃）；主动技能不减半。
- 劣势补偿：存活人数少的一方每人每回合获得人数差张防御牌（塔/无人机不算）。
- 存档：主菜单「继续游戏」可恢复团战进度。
- AI：仅保留简单随机 AI（用户要求暂时取消熟练/地狱）。
