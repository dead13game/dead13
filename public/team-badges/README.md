# 联赛队标目录

把球队队标图片放在本目录，命名规则：**`{球队id}.png`**

| 文件名   | 球队          |
| -------- | ------------- |
| `1.png`  | 曼城 🔵       |
| `2.png`  | 利物浦 🔴     |
| `3.png`  | 阿森纳 🔴     |
| `4.png`  | 曼联 🔴       |
| `5.png`  | 切尔西 🔵     |
| `6.png`  | 热刺 ⚪       |
| `7.png`  | 纽卡斯尔联 ⚫ |
| `8.png`  | 埃弗顿 🔵     |
| `9.png`  | 西汉姆联 🟤   |
| `10.png` | 狼队 🟠       |

- 图片放入后自动生效，无需改代码（接口：`getTeamBadge(teamId)`，见 `src/game/leagueConstants.js`）
- 推荐尺寸：128×128 或 256×256，正方形 PNG（带透明背景效果最佳）
- 未放入图片的球队在 UI 上回退显示 emoji
