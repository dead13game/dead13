# 亡命十三街 · 单机模式设计文档（技能卡肉鸽）

> 状态：草案 v0.2（设计层完善版）
> 修订记录：v0.1 初稿 → v0.2 补全战斗时序/数值总表/事件模板/阶段扩展 → v0.3 战斗机制重构：抽3选2（行动力+抽牌数）、月圆之夜式牌库/坟场循环、术语「费用」→「行动力」→ v0.4 大数值适配：同名牌堆叠显示 ×n、出牌选数量、手牌按种类计上限、抽牌数 1-13 直接用 → v0.5 决策确认：扑克=纯资源层（花色无战斗加成）、防御=护盾值、卡池用 13 张草案 → v0.6 玛薇卡斗志重设计：破盾得斗志（=护盾伤害量）、每 5 层行动力 +1、每场战斗独立 → v0.7 AI 敌人随机策略、首领专属 BUFF、存档不重试、剧情预留 → v0.8 最小闭环扩为 7 节点（战斗→事件→商店→战斗→营地→精英→首领），数值/经济/经验预算同步更新

> 本作特色：扑克牌 = 行动资源 & 检定工具；技能卡 = 构筑主体；CRPG 属性修正

---

## 1. 目标与核心循环

做一个**单机跑图肉鸽**：选 1 个角色，沿章节地图前进，在节点之间战斗、构筑技能卡组、强化属性，击败章节首领后进入下一章，通关或死亡重开。

```
选角色(玛薇卡) → 章节地图选路 → 节点(战斗/精英/商店/事件/营地/首领)
→ 1v1 战斗(抽3选2扑克定行动力/抽牌数，技能卡打出) → 奖励(技能卡/金币/经验)
→ 商店买卡/删卡，营地回血/升级卡 → 章节首领 → 下一章 → 通关/重开
```

**三根支柱**：跑图决策（路线选择）、卡组构筑（技能卡逐渐成型）、随机与重开（肉鸽循环）。

## 3. 卡牌体系

### 3.1 扑克牌（基础层：资源 + 检定）

- **行动资源**：每回合开始抽 **3 张**扑克 → 玩家选 2 张：点数之和 = 本回合**行动力**；剩 1 张：点数 = **抽牌数**（1-13，直接抽，见 5.2）。花色映射：♠=物理、♦=法术、♣=防御、♥=治疗/检定优势（花色仅用于事件检定 ♥ 重抽，**战斗中花色无加成效果**）。
- **事件检定**：抽 1 张扑克，点数 + 相关属性修正 vs 难度 DC，成功/失败走不同分支；检定失败时 ♥ 花色可重抽 1 次。

### 3.2 技能卡（构筑层：战斗主体）

技能卡由角色专属卡池 + 通用卡池构成，每张卡：

```
字段：id / name / type(physical|magic|defense|utility) / actionCost(4-12) / effect 描述 / 专属角色?
```

**示例卡表（数值草案）**

| 卡名 | 类型 | 行动力 | 效果 |
| --- | --- | --- | --- |
| 重击 | 物理 | 9 | 6 + 力量修正 伤害 |
| 连击 | 物理 | 12 | 3 + 力量修正 伤害，×2 段 |
| 火球 | 法术 | 12 | 5 + 法力修正 伤害 |
| 治愈 | 法术 | 8 | 4 + 法力修正 回血 |
| 格挡 | 防御 | 4 | 4 + 防御修正 减伤（持续至下回合） |
| 狂怒 | 功能 | 4 | 斗志 +2（玛薇卡专属联动） |

**获取途径**：战斗胜利奖励（3 选 1）、商店购买、事件奖励。
**构筑操作**：商店买卡 / 删卡（付费）/ 营地升级卡（卡面数值 +2）。

### 3.3 角色技能（职业层）

- 首发玛薇卡：**斗志**——对敌方护盾造成伤害时获得等量斗志，每 5 层斗志行动力 +1（详见 5.4）；与狂怒卡联动。角色技能随角色等级强化（阶段二扩展其他角色）。
- 角色技能随角色等级强化（阶段二扩展其他角色）。

| 属性 | 修正的卡牌/行为 |
| --- | --- |
| 力量 | ♠ 物理攻击卡伤害 |

| 防御 | ♣ 防御卡减伤值 + 最大 HP |

- 升级：每级 +2 属性点，自由分配

## 5. 战斗系统（1v1，独立于现有多人战斗）

> 现有 combat.js 是多人扑克对战（攻击/防御/赌命/结盟），与技能卡战斗差异大，**新建 solo 战斗逻辑**；PIXI 牌桌渲染、AI、日志可复用。

### 5.1 回合时序

```
玩家回合开始
  ├─ 抽 3 张扑克 → 玩家选 2 张：点数之和 = 本回合行动力；剩 1 张点数 = 抽牌数
  ├─ 按抽牌数从技能牌堆顶部抽牌（进入手牌）
  ├─ 出牌阶段：点击牌格选数量，消耗行动力打出技能卡（无出牌次数限制，行动力决定一切）
  └─ 主动结束回合（行动力不跨回合累计）
敌人回合
  ├─ AI 同规则：抽 3 张，自动选 2 张最大点数作行动力，剩 1 张为抽牌数
  └─ 结算后回到玩家回合
交替进行，直至一方 HP ≤ 0，或 30 回合平局（HP 高者胜，相同则玩家败）
```

### 5.2 行动力与抽牌数结算

- 扑克点数：A=1，2-10 面值，J/Q/K=11/12/13
- **行动力** = 玩家选中的 2 张点数之和，范围 2-26（3 选 2 取较大时平均约 17）；不跨回合累计
- **抽牌数** = 剩余 1 张点数，范围 1-13，**直接作为本回合抽技能卡张数**（同名牌自动堆叠显示，见 5.3，无需上限截断）
- **3 选 2 的抉择**：高行动力（多出牌）vs 高抽牌数（多上手）——是本作抽牌博弈的核心
- 行动力仅用于打出技能卡，不可兑换其他资源
- 扑克牌堆不足 3 张时重新洗牌补足（复用现有洗牌逻辑）

### 5.3 牌库机制（月圆之夜式 + 同名牌堆叠）

- **战斗外**：技能卡牌库由构筑积累（初始卡组 + 战斗奖励 + 商店购买），**同名牌可多张**（如火球可累计持有 10 张）
- **战斗开始**：牌库随机堆叠成牌堆（洗牌）
- **抽牌**：每回合按抽牌数（1-13 张）从牌堆**顶部**抽牌
- **同名牌堆叠**：抽出的相同技能卡在手牌中**聚合为 1 格**，标注数量 ×n（例：抽 12 张含 7 张火球 → 手牌显示「火球 ×7」）——大数值规模下的手牌可视化方案
- **出牌**：点击牌格 → 选择打出数量 n（1 ≤ n ≤ 持有数）→ 消耗 n × actionCost 行动力；同名牌一次可打出多张
- **使用过的牌** → **坟场**（坟场中同名牌同样聚合计数，洗回时按张数展开）
- **牌堆为空** → 将坟场所有牌重新随机打乱，放回牌堆（循环）
- **手牌上限 = 种类上限 6**（计数不占格）；抽到新种类且种类已满 → 该牌进坟场（爆牌）
- **无出牌次数限制**：行动力是唯一约束（行动力够、手牌有即可任意出牌）

### 5.3a 防御机制（护盾值）

- 防御类卡（格挡/铁壁/回气）打出后获得**护盾值**（数值见 12.2，如格挡 = 4 + 防御修正）
- 敌方攻击时**先扣护盾值，剩余伤害再扣 HP**（护盾不为负数，扣完即止）
- 护盾值**跨回合保留**（不清零），被攻击消耗或持续累积；战斗结束清零
- 与多人版"防御牌实体垫身前"不同：单机版护盾是纯数值 buff，实现更轻

### 5.4 斗志机制（玛薇卡，精确规则）

- **特殊标签**：玛薇卡自带「斗志」计数器（仅玛薇卡有）
- **获取方式**：对敌方**护盾造成伤害**时，斗志增加量 = 对护盾的伤害量（例：火球造成 12 伤，敌方护盾 8 点被扣完 → 斗志 +8，余 4 伤扣 HP）
- **效果**：每 **5 层斗志 → 行动力 +1**（向下取整，如斗志 12 → 行动力 +2），作用于本回合出牌阶段
- **额外途径**：功能卡「狂怒」打出后斗志 +2
- **每场战斗独立**：斗志战斗开始时归零、战斗结束清除，不跨战斗保留
- 深度机制（斗志更多联动）后续版本补充，本版仅实现以上基础规则

### 5.5 AI 敌人决策

**通用规则（普通/精英/首领一致）**：
- **抽 3 选 2 决策**：先平衡选择——保证行动力不极端（优先选使行动力 ≥ 12 的组合），再兼顾抽牌数
- **出牌（慢放 + 纯随机）**：从所有可出的攻击/防御卡中**纯随机**均匀选取（无优先级）；每次宣布 1 种牌（高亮 + 显示数量 ×n），延迟 **1.5s** 后打出，再宣布下一张，**直到行动力不足或手牌打空才结束**（无消耗上限）
- **怪物强度来源**：数值加成（HP/伤害）+ **预设牌组**（每个敌人配一套预置技能卡牌组，强度由牌组决定）
- 不出功能卡（狂怒/专注），出牌范围 = 预设牌组中的攻击/防御卡

| 敌人 | 数值 | 预设牌组倾向 |
| --- | --- | --- |
| 普通 | HP 20，攻击 3-4 伤 | 纯攻击卡（猛击×4 / 重击×2） |
| 精英 | HP 30，攻击 4-5 伤 | 攻击+防御（重击×3 / 火球×2 / 格挡×2），开局优先铺护盾 |
| 首领 | HP 40，攻击 5-6 伤 | 高费攻击+护盾（连击×2 / 火球×2 / 铁壁×2），**带专属 BUFF** |

**首领专属 BUFF**：复用现有角色的特殊效果作为首领机制（例：首领带「斗志」标签——玩家对首领护盾造成伤害时，首领斗志 += 破盾量，每 5 层首领行动力 +1）。各首领的 BUFF 在后续内容设计时逐个指定。

### 5.6 战斗结束与奖励

- 玩家胜：金币 + 技能卡 3 选 1 + 经验（数值见数值设计章节）
- 玩家败：单机模式结束 → 结算界面 → 重开
- 30 回合平局：HP 比例高者胜；相同则玩家败（鼓励进攻，防龟缩拖平）

## 6. 跑图结构

```
第1章(最小闭环)         后续章节(阶段二+)
[战斗]→[事件]→[商店]→[精英]→[首领]    路线分支/更多节点/多结局
```

**节点类型**：

| 节点 | 内容 | 奖励 |
| --- | --- | --- |
| 战斗 | 1v1 普通敌人 | 金币 + 技能卡 3 选 1 + 经验 |
| 精英 | 1v1 精英敌人（强化数值） | 金币多 + 稀有卡池 |
| 商店 | 买卡/删卡/回血 | 消耗金币 |
| 事件 | CRPG 对话分支 + 扑克检定 | 金币/卡/属性点/HP，视选择 |
| 营地 | 回血（消耗金币）或升级 1 张卡 | — |
| 首领 | 章节 Boss | 进入下一章 / 通关 |

### 6.1 最小闭环节点链配置

| 序号 | 节点 | 内容 | 掉落（详见 12.5/12.6） |
| --- | --- | --- | --- |
| 1 | 战斗 | 普通敌人（HP 20） | 金币 8-15 + 10 经验 + 普通卡 3 选 1 |
| 2 | 事件 | 岔路事件（检定，见 6.2） | 视选择：金币/卡/属性点 |
| 3 | 商店 | 买卡/删卡/回血 | 消耗金币 |
| 4 | 战斗 | 普通敌人（HP 20，第二轮构筑补强） | 金币 8-15 + 10 经验 + 普通卡 3 选 1 |
| 5 | 营地 | 回血（消耗金币）或升级 1 张卡 | — |
| 6 | 精英 | 精英敌人（HP 30，开局护盾） | 金币 15-25 + 20 经验 + 普/稀 3 选 1 |
| 7 | 首领 | 首领（HP 40，预设牌组 + 专属 BUFF，见 5.5） | 金币 30-45 + 40 经验 + 稀卡 3 选 1 + 1 属性点 → 通关 |

节点为**固定顺序链**（阶段一不做选路）；玩家死亡即整局结束重开（不可重试）。打完首领约 **4 级**、金币收入约 **70-115**（见 12.4/12.6 预算），足够 2-3 次商店消费 + 1 次营地休整。

### 6.2 事件设计（模板）

每个事件 = 一段描述文本 + 2-3 个选项，其中 ≥1 个选项带**扑克检定**：

```
事件结构：
  id / 标题 / 描述文本
  options: [
    { text, type: 'fixed'|'check', attr: 'str'|'mag'|'def', dc,  // check 项
      success: { gold/卡/属性/HP 奖励 }, fail: { 后果 } }
  ]
```

**最小闭环事件 2 个（示例）**：

1. **`岔路猎手`**：一名猎手拦住去路，提出要么付过路费，要么和他比试力量。
   - 选项 A（固定）：付 10 金币通过
   - 选项 B（检定·力量 DC 12）：抽扑克 + 力量修正 ≥ 12 → 免费通过 + 得 5 金币；失败 → 扣 5 HP（被推搡）
   - 选项 C（固定）：绕路，损失 1 张卡（随机删一张）

2. **`神秘商人`**：黑市商人兜售一张稀有的法术卡，但价格可疑。
   - 选项 A（固定）：花 25 金币购买（从稀有卡池随机 1 张）
   - 选项 B（检定·魅力不在 3 维内，改用**法力** DC 13 说服）：成功 → 15 金币购入；失败 → 25 金币购入（谈崩价）
   - 选项 C：不买，得 5 金币（商人赏识你的谨慎）

**检定规则**：抽 1 张扑克（点数 1-13，A=1，J/Q/K=11/12/13）+ 对应属性修正 vs DC；♥ 花色检定失败时可重抽 1 次（见 3.1）。DC 区间 10-14，随章节递增。

### 6.3 地图呈现设计

- 竖版节点链（复用项目竖屏布局经验）：节点从上到下排列，当前节点高亮，已过节点打勾
- 节点图标：⚔️战斗 / 💀精英 / 🛒商店 / ❓事件 / 🏕️营地 / 👑首领

## 7. 成长系统（第一阶段：纯局内）

### 7.1 经验与等级

- 战斗胜利得经验（12.5 奖励表），攒够即升级（12.4 经验曲线）
- 升级：+2 属性点，自由分配至力量/法力/防御；属性变化即时反映在卡牌数值与最大 HP（HP = 20 + 防御 × 2）
- 升级动画/提示在节点结算界面展示，玩家确认后继续推进

### 7.2 金币经济循环

- **来源**：战斗/精英/首领奖励、事件选项（12.5/6.2）
- **消耗**：商店买卡/删卡/回血/升级卡（12.6）
- 预算：1 章收入 70-115 金币，支持 2-3 次商店消费 + 1 次营地休整——构筑"选择有限"的压力（买什么/删哪张/要不要回血，是核心决策）

### 7.3 卡组构筑流程

- **获得**：战斗奖励 3 选 1、商店购买、事件奖励
- **删除**：商店付费删卡（价格递增，12.6），瘦身卡组提高关键卡上手率
- **升级**：营地或商店升级 1 张卡（卡面数值 +2，12.6）
- 构筑目标：围绕角色机制（玛薇卡 = 斗志流：堆攻击卡 + 狂怒）形成套路

### 7.4 局外元进度（阶段二+）

- 解锁角色、卡牌图鉴、初始金币/属性加成、成就
- 本阶段仅预留数据字段（soloState 中占位），不实现逻辑

## 9. 最小闭环范围（第一个里程碑）

- 1 个章节：`战斗 → 事件 → 商店 → 战斗 → 营地 → 精英 → 首领`（7 节点固定链，先不做选路）
- 玛薇卡角色 + 初始技能卡 4 张（猛击 ×2 / 重击 ×1 / 格挡 ×1，见 12.2）
- 商店/奖励卡池 10 种（连击/破甲/奥术冲击/冰锥/治愈/火球/回气/铁壁/狂怒/专注，见 12.2），商店可买
- 敌人 3 种（普通/精英/首领）AI 1v1，首领带专属 BUFF（见 5.5）
- 事件 2 个（含 1 次扑克检定）
- 通关 = 击败首领（单结局）
- **存档**：战斗中可保存退出（复用经典模式 localStorage 机制）；**死亡不可重试**，整局重开（回到章节起点，保留解锁数据字段占位）

**验收标准**：从主菜单进入 → 打完 7 节点 → 首领战 → 通关/死亡重开，全程无崩溃，`npm run test` 通过，`npm run build` 通过。

### 12.7 平衡设计原则

- 抽 3 选 2 + 不跨回合累计：把随机性转化为"行动力 vs 抽牌数"的玩家抉择，而非运气碾压
- 每回合出 3 张上限：防止手牌爆发一回合秒杀，保证 AI 有反应空间
- 30 回合平局判负：压缩龟缩玩法，节奏正向
- 精英/首领的"开局防御"与"狂暴"：制造回合压力点，逼玩家构筑进攻与防御的平衡
