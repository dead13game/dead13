# 亡命十三街 · 单机剧情文本落点清单

> 用途：**剧情文本填充清单**——列出所有需要写剧情文本的位置，由作者逐个填充。
> 依据：`docs/solo-story-design.md`（设定层，**定稿 v1.0**）；agent 稿仅作炼金线参考（牧师线 agent 稿已舍弃）。
> 落点状态图例：✅ 可填充｜⏳ 待设计（设计定了再补）｜🖊 填充中/待审
> 设定状态（对应 design 三态）：🔒 定稿（已明确，需要文本）｜⏳ 待定（未讨论完善）｜🔮 谜团（成品也不解释，文本不揭示）
> 约束：第二人称「你」；隐藏设定（同一人）只暗示不揭示；灭世程序=🔮谜团；圣言=言灵系；认亲特征=右肩胎记；**主角时间感断裂 + 身体停止生长（非失忆症）**——原生人格认知停在 6 岁（6 岁去河边玩后沉睡，12 岁苏醒只当睡了一觉）；**身体始终 6 岁孩童外表**（12 岁年龄、6 岁外表），完全未察觉 6 年已过。

## 第二局 · 炼金术师局（12 岁起原生人格，agent 稿通过可参考）

> **流程序列（🔒 定稿，design §5.2）**：
> - **第 1 章**：(田舍) 演出 → 普通 → 事件 → 普通 → 商店 → 普通 → 精英 → (炼金网络) 事件 → 普通 → 事件 → 普通 → 商店 → 营地 → **首领·守门人**
> - **第 2 章**：(城镇) 事件·传闻 → 普通 → 事件·武夫 → 普通 → 商店 → 精英·进城战 → (教会据点) 事件·档案 → 普通 → 商店 → 普通 → 营地 → **首领·执事**
> - **第 3 章**：(大教堂) 演出·赎罪 → 普通 → 事件 → 普通 → 商店 → 普通 → 营地 → **首领·圣骑士长** → 灭世程序 → 死亡
> 节点构造规则（作者审批，作者意见优先）：普通每场景连续≤2、每章≥3；事件不邻演出/商店；商店每场景 1 个；营地首领前；切场景处精英/首领。
