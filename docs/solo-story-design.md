# 亡命十三街 · 单机剧情设定笔记

> 状态：讨论中（v0.1，随讨论持续更新）
> 定位：单机模式剧情世界观与叙事结构的设定记录（纯文档，不涉及代码）
> 关联：玩法设计见 `docs/solo-roguelike-design.md`；本笔记只记剧情

---

## 1. 世界观定位

- **时代**：欧洲中世纪（宗教为底色；存在士阶层；人均寿命短、十二岁可成婚）
- **剧情世界独立**：与多人对战舞台「亡命十三街」互不解释，剧情世界不涉及跨作品角色（原神/星铁/Re0 等）
- **炼金术是设定底色**，不是主线本身

## 2. 势力（三派系 + 一潜伏势力）

| 势力 | 定位 | 说明 |
| --- | --- | --- |
| **教会** | 最大势力 | 本负责镇压魔鬼；如今派系分裂、内部纷争；拉拢/利用炼金术士 |
| **炼金术士** | 异端 | 暗中活动，被教会视为异端 |
| **武夫（士阶层）** | 中立势力 | 无归属、武艺高强；玩家可拉拢 / 敌对 / 无视，影响走向与可获取线索 |
| **魔鬼 / 地狱生物** | 潜伏 | 真实存在 + 教会滥用「魔鬼」之名清洗异端（真相与宣传并存，留给玩家辨别） |

## 3. 主角

- **双人格，本质是同一人**（⚠️ 隐藏设定：玩家需在两局游玩中自行推理出，开发者视角已知）
  - **牧师**（教会人格）：主角的 6~12 岁
  - **炼金术师**（原生人格）：主角的 12 岁起，直到发现灭世程序
- 从小患有「短时间失忆」（记忆断层）的病
- 动机线：**复仇 → 真相 → 赎罪**
- 炼金术知识来源：0-6 岁亲父启蒙（模糊记忆碎片）+ 12 岁原生人格苏醒后自学亲父笔记/实验室

## 4. 时间线（12 岁版，已确认）

1. **0-6 岁**：与亲父母（炼金术士）和姐姐生活在田舍（无妈妈）；亲父开始教炼金术基础
2. **6 岁**：走丢（掉河）→ 失忆
3. **6-12 岁**：被教会收养（养父=助祭，即将升职），形成教会人格
4. **12 岁**：教会发现亲父母暗中支持敌对教会派系 → 派主角灭口；亲父母认出他、毫无戒备 → 被杀；主角发现全家合影油画、日记、满屋寻人启事 → 头疼晕倒，原生人格苏醒
5. **12 岁后**：原生人格在田舍醒来，发现家人（父+姐）倒毙、满屋狼藉 → 带着悔恨与不甘调查 → 线索指向教会 → 追至大教堂（灭世程序）

> 注：炼金线文本「12 岁被教炼金术」「以为只是去河边玩了一次」是原生人格视角的叙述，与客观时间线共存（失忆症/记忆断层），无需改动文本。

## 5. 叙事结构（双局碎片化）

- **两个独立可玩角色**：牧师 / 炼金术师（现阶段复用玛薇卡代码占位，后续专门设计技能）
- 每个角色一盘独立的肉鸽（跑图），**碎片化叙事**：局内通过探索收集剧情线索，只看到自己视角的碎片
- **至少玩两局（两角色各一局）→ 两局各自通关 → 补全结局演出** → 看清灭世程序全貌（无需第三局）
- 两局**终点不同**：各自结束于自己的故事终点，**合起来才触及灭世程序**
- 游玩顺序：自由选择，**推荐先牧师**（先看刽子手，再看受害者家庭视角的复仇）
- 局内目标：「**下一条线索**」式指引（无任务文本，保持目标感 + 碎片感）

## 6. 剧情碎片（线索）载体

1. **事件文本**：现有 event desc / options 结构承载
2. **可收集物**：寻人启事、日记、全家合影油画、教会文书等
3. **战斗台词**：敌人/首领台词携带碎片（如敌人认识主角、提到「助祭家的孩子」）

## 7. 结局

- 主线终点：**大教堂 · 灭世程序**（当前版本剧情到此结束）
- 结局分支体系：暂缓，先主线后结局（后续再议）
