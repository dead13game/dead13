# 亡命十三街 · 单机剧情设定笔记

> 状态：**定稿 v1.0**（2026-08-15）
> 定位：单机模式剧情世界观与叙事结构的设定记录（纯文档，不涉及代码）
> 关联：玩法设计见 `docs/solo-roguelike-design.md`；文本落点见 `docs/solo-story-text-points.md`

> **状态标记（三态）**：
> - 🔒 **定稿**：已明确的内容，需要具体文本（文本落点见清单文档）
> - ⏳ **待定**：当前游戏版本未讨论完善的剧情要素（开放讨论）
> - 🔮 **谜团**：当前版本哪怕是成品也不做解释的要素（玩家/文本都不会揭示）

## 1. 世界观定位

- **时代**：欧洲中世纪（宗教为底色；存在士阶层；人均寿命短、十二岁可成婚）
- **剧情世界独立**：与多人对战舞台「亡命十三街」互不解释，剧情世界不涉及跨作品角色（原神/星铁/Re0 等）
- **炼金术是设定底色**，不是主线本身

## 2. 势力（三派系 + 一潜伏势力）

| 势力 | 定位 | 说明 |
| --- | --- | --- |
| **教会** | 最大势力 | 本负责镇压魔鬼；如今派系分裂、内部纷争；拉拢/利用炼金术士 |
| **炼金术士** | 异端 | 暗中活动，被教会视为异端 |
| **武夫（士阶层）** | 中立势力 | 无归属、武艺高强；玩家可拉拢 / 敌对 / 无视，影响走向与可获取线索 |
| **魔鬼 / 地狱生物** | 潜伏 | 真实存在 + 教会滥用「魔鬼」之名清洗异端（真相与宣传并存，留给玩家辨别） |

## 3. 主角

- **双人格，本质是同一人**（⚠️ 隐藏设定：玩家需在两局游玩中自行推理出，开发者视角已知）
  - **牧师**（教会人格）：主角的 6~12 岁
  - **炼金术师**（原生人格）：主角的 12 岁起，直到发现灭世程序
- **人格切换 · 时间感断裂（非失忆症）**：主角默认人格（原生人格）的认知停在 6 岁——6 岁去河边玩后「沉睡」（教会人格接管），12 岁原生人格苏醒时只当睡了一觉，**未察觉已过 6 年**；这是人格切换导致的时间感知断裂，不是「短时间失忆」的病
- **身体停止生长**：6 岁掉河后身体不再长大（始终 6 岁孩童外表）——12 岁（年龄/教会档案）苏醒时外表仍是 6 岁，因此毫无异样、完全未察觉时间流逝；**原因 🔮 谜团**（成品也不解释，与「看似小孩、实际年龄大」呼应）；文本体现：仅在炼金局开头自然暗示，其他段落不刻意强调
- 动机线：**复仇 → 真相 → 赎罪**
- 炼金术知识来源：0-6 岁亲父启蒙（**完整记忆**，原生人格以为最近发生）+ 12 岁原生人格苏醒后自学亲父笔记/实验室
- **圣言（教会能力）**：**言灵系**——说出的言语本身带力量（参照《龙族》言灵：靠口令/吟诵触发，非光系/金光）；教会人格 6 年训练习得，原生人格苏醒后身体仍残留痕迹，被炼金术师察觉（成为被同行敌视的原因）

## 4. 时间线（12 岁版，已确认）

1. **0-6 岁**：与亲父母（炼金术士）和姐姐生活在田舍（无妈妈）；亲父开始教炼金术基础
2. **6 岁**：去河边玩 → 掉河（原生人格沉睡，教会人格接管）→ 被教会捡到
3. **6-12 岁**：被教会收养（养父身份：**归牧师线待定**——原记「助祭，即将升职」不作数），教会人格主导
4. **12 岁**：教会派主角灭口（对象含姐姐）【灭口动机：🔮 **谜团**——不定义教会为何灭门，炼金线中玩家只知「教会下的令」】。Boss 战（牧师局终点）：亲父凭**右肩胎记**认出主角并试图相认，但牧师（教会人格）不信——认为这是异端的谎言/骗术，一味攻击，杀死亲父。战后发现全家合影油画、日记、满屋寻人启事，并见姐姐尸身（攥着圆石/寻人启事倒毙）→ 头疼晕倒 → 原生人格苏醒（牧师局收尾演出，至此牧师局结束）
5. **12 岁后**：原生人格在田舍醒来（在床上醒来，只当睡了一觉，**未察觉已过 6 年**）→ 发现家人（父+姐）倒毙、满屋狼藉 → 带着悔恨与不甘调查 → 线索指向教会 → 追至大教堂（灭世程序）

> 注：炼金线文本「以为只是去河边玩了一次」即原生人格的认知——他 6 岁去河边玩后沉睡，12 岁苏醒只当睡了一觉；「12 岁被教炼金术」等叙述与其时间感断裂共存（他以为那些事就是最近发生的），无需对齐客观时间线。

## 5. 叙事结构（双局碎片化）

- **两个独立可玩角色**：牧师 / 炼金术师（现阶段复用玛薇卡代码占位，后续专门设计技能）
- 每个角色一盘独立的肉鸽（跑图），**碎片化叙事**：局内通过探索收集剧情线索，只看到自己视角的碎片
- **至少玩两局（两角色各一局）→ 两局各自通关 → 补全结局演出** → 看清灭世程序全貌（无需第三局）
- 两局**终点不同**：各自结束于自己的故事终点，**合起来才触及灭世程序**
- 游玩顺序：自由选择，**推荐先牧师**——先以刽子手身份（教会人格）经历灭门，再以被害家庭的幸存者（原生人格）追查真相，最终拼出「凶手就是自己」的隐藏设定（两局同一人）
- 局内目标：「**下一条线索**」式指引（无任务文本，保持目标感 + 碎片感）
- **玩家视角**：第二人称「你」——两局共用同一「你」，是隐藏设定（同一人）的暗示载体，不得改为第三人称
- **牧师局结局**：战胜最终 Boss「神秘炼金术师」——实为亲生父亲（12 岁灭口任务的终点），战胜后牧师局直接结束
- **炼金术师局结局**：战胜大教堂守卫 → 灭世程序启动 → 炼金术师来不及庆祝胜利便已死亡（当前版本剧情终点）
- **首领设计原则**：每个首领都有身份 + 推动剧情/给出信息的对话（首领不是纯战斗，是剧情信息节点）

## 5.2 炼金术师局 · 调查链

- **5 场景（叙事阶段）**：田舍（起点：醒来发现家人倒毙、满屋狼藉）→ 炼金网络（炼金同行）→ 城镇（打听/收集线索）→ 教会据点（证据链指向教会）→ 大教堂（终点）
- **途中敌人**：
  - **其他炼金术师**：认为主角身上有奇怪的「圣言」——主角使用了 6 年教会能力的痕迹，被同行视为教会奸细/异类（第 1 章普通战斗敌人）
  - **教会的人**：阵营敌对（第 2 章执法者、第 3 章守卫）
- **武夫（中立势力，已确认）**：城镇（第 2 章）中立出场、给方向性线索（**指向教会据点**——炼金网络已过）；**无拉拢/敌对分支**（当前版本写死）
- **真相揭示**：后期揭开「凶手是自己」——前期复仇驱动 → 后期真相 → 赎罪驱动至终局
- **最终 Boss**：大教堂守卫 = **教会圣骑士长**
- **圣骑士长不知情**：他不知道灭世程序的存在——他是大教堂守卫，不是灭世程序的看守；灭世程序隐藏于大教堂，知情者极少（🔮 **谜团**：谁建造、谁知道，成品也不解释）
- **首领阵容（3 个，已确认）**：炼金网络·守门人 → 教会据点·执事 → 大教堂·圣骑士长（最终）；切场景处部署精英/首领，三个首领都有身份 + 推动剧情的对话
- **「圣言」**：言灵系教会能力（见 §3），6 年训练残留痕迹，被炼金术师察觉——成为炼金同行敌视他的原因

### 炼金局流程结构（🔒 定稿）

- **3 章（以 3 首领为章界）× 5 场景**：田舍、城镇、炼金网络、教会据点、大教堂
- **节点构造规则**（⚠️ 需作者审批；作者如有意见违背本规则，一次性以作者决定为准）：
  - 普通战斗：每场景**连续 ≤ 2**、每章**总量 ≥ 3**
  - **事件与演出不相邻**；**事件与商店不相邻**
  - 演出/事件节点数量与位置**依据剧情设计**
  - **商店：每个场景 1 个**（5 场景 → 第 1 章 2、第 2 章 2、第 3 章 1）
  - **营地：首领前**（每章 1 个）
  - 切场景处部署**精英/首领**
- **三章节点序列（定稿）**：
  - **第 1 章**：(田舍) 演出 → 普通 → 事件 → 普通 → 商店 → 普通 → 精英 → (炼金网络) 事件 → 普通 → 事件 → 普通 → 商店 → 营地 → **首领·守门人**
  - **第 2 章**：(城镇) 事件·传闻 → 普通 → 事件·武夫 → 普通 → 商店 → 精英·进城战 → (教会据点) 事件·档案 → 普通 → 商店 → 普通 → 营地 → **首领·执事**
  - **第 3 章**：(大教堂) 演出·赎罪 → 普通 → 事件 → 普通 → 商店 → 普通 → 营地 → **首领·圣骑士长** → 灭世程序 → 死亡
- 死亡整局重开（沿用现有单机规则）
- 线索卡发放：关键节点必得（田舍开局、首领战后等）+ 事件/探索补充（机制见 §6）
- 节点级战斗/敌人/数值排布归 `docs/solo-roguelike-design.md`（玩法文档）

## 5.3 牧师局 · 教会任务链（对称设计）

- ⚠️ **教会线设计状态**：作者未参与设计、未通过教会线任何细节——仅时间线骨架（§4 第 3-4 步）为已确认；其余（教会内部、助祭/执事等人物、训练/任务过程、阶段/敌人/首领）**全部待作者设计**；agent 稿与先前聊天记录中的教会线内容一律不作数
- 与炼金局**对称**：采用同一叙事框架（阶段化 + 首领对话 + 4 种载体），两局互为镜像
- **圣言两视角**：牧师局=正常使用（教会人格本命能力）；炼金局=残留痕迹被同行察觉——同一能力、两种视角
- **具体设计后置**：阶段划分、敌人构成、首领阵容后续再设计（当前聚焦炼金局）

## 6. 剧情呈现载体（4 种）

1. **线索卡牌**（特殊类型卡）：含一段文本；**可升级、可联动**，升级/联动后解锁更多信息；**局外可查看**；区别于战斗牌组——不进牌库、战斗不抽取。获取：**关键剧情节点必得**（保证主线推进）+ 事件/探索随机补充；升级靠局内资源；联动靠收集到关联线索自动解锁
2. **事件文本**：现有 event desc / options 结构承载
3. **首领对话文本**：每个首领都有身份 + 推动剧情/给出信息的对话
4. **特殊地点剧情演出**：如田舍醒来发现家人倒毙、发现油画/寻人启事等关键场景

## 7. 结局

- **牧师局终点**：战胜最终 Boss「神秘炼金术师」（实为亲父）→ 牧师局结束
- **炼金术师局终点**：战胜大教堂守卫 → 灭世程序启动 → 主角死亡（来不及庆祝胜利）
- 两局通关后补全结局演出：看清灭世程序全貌
- 主线终点：**大教堂 · 灭世程序**（当前版本剧情到此结束）
- 结局分支体系：**确认无分支**——两局各自单一终点（大教堂灭世程序），玩家无法改变；分支留待未来版本
