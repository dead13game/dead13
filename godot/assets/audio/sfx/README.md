# 音效目录

把音效文件放在本目录，命名规则：**`{音效名}.mp3`**（推荐 mp3 格式，其他浏览器支持的格式如 .ogg/.wav 也可——把 SoundManager.js 里对应的扩展名改成实际文件即可，或直接用 .mp3）。

## 音效文件表

| 文件名             | 类型       | 触发时机                                        |
| ------------------ | ---------- | ----------------------------------------------- |
| `bgm.mp3`          | 主背景音乐 | 进入游戏后首次点击/按键时开始，循环播放         |
| `attack.mp3`       | 攻击       | 发起攻击摸牌时                                  |
| `defense.mp3`      | 防御       | 执行防御摸防御牌时                              |
| `gamble.mp3`       | 赌命       | 执行赌命抽牌时                                  |
| `skill.mp3`        | 技能       | 成功释放主动技能时                              |
| `shield-break.mp3` | 破盾       | 防御牌被击穿（伤害穿透防御）时                  |
| `kill.mp3`         | 击杀       | 有玩家阵亡时                                    |
| `match-end.mp3`    | 对局结束   | 世界杯/联赛单场比赛结束（团灭/回合上限/点球）时 |
| `trap-break.mp3`   | 陷阱被破   | 攻击值 > 陷阱值，击破陷阱时                     |
| `trap-reflect.mp3` | 陷阱反弹   | 攻击值 < 陷阱值，陷阱反弹攻击者时               |
| `trap-tie.mp3`     | 陷阱平局   | 攻击值 = 陷阱值，双方受伤时                     |

## 使用说明

- 文件放入后自动生效，**无需改代码**（接口：`recordSound` 记录事件 → `useSoundSync` 监听 → `SoundManager` 播放）
- 未放入的音效自动静默跳过，不影响游戏运行
- 同一音效 120ms 内不重复播放（防止同帧多事件爆音）
- 推荐：短音效 0.3~1.5s；BGM 建议 30s+，可循环
- 音量接口：`SoundManager.setVolume(v)`（音效，默认 0.8）、`setBgmVolume(v)`（BGM，默认 0.5）、`setMuted(bool)`（总静音）
